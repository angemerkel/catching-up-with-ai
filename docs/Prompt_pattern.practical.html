3  Prompt Pattern (practical)

– A practical, example-driven overview.

3.1 Core Prompt Patterns

3.1.1 Persona Pattern

Helps control tone, expertise, cultural assumptions.

Example:

“Act as a senior bioinformatician experienced in single-cell epigenomics. Provide actionable suggestions.”

3.1.2 Audience Persona Pattern

Tell GPT who you are so explanations match your background.

Example:

“Assume I am new to machine learning but familiar with R and statistics. Explain what a transformer is.”

3.1.3 Question Refinement

GPT improves your question. Useful for technical tasks where question quality matters.

Example:

“When I ask you something unclear, suggest a sharper version first and ask if I want to use it.”

3.1.4 Few-shot Prompting

You show examples (introduce training data) → GPT follows your pattern. Useful for labeling, transformations, extraction tasks.

Example:

Input: ATGCGT

Output: reversed sequence: TGCGTA


Prompt:

Input: AACCAT

Output:

GPT continues with the intended pattern.

3.1.5 Flipped Interaction

GPT asks you the questions.

Example:

“Ask me clarifying questions until you can design a workshop outline. When you have enough information, present the final outline.”

3.1.6 Chain of Thought

Explicit reasoning steps.

Example:

“Show your reasoning in short bullet points and end with a boxed final answer.”

Helps when solving problems or planning.

3.1.7 ReAct Prompting

Reason → take external action → reason → answer.

Example:

“Search PubMed for recent papers on DNA methylation in HSCs, summarize top 3 findings, and explain how they relate to AML biology.”

(Assuming GPT has tools activated.)

3.1.8 Alternative Approaches

Ask for multiple solutions. (or strategy for approaches)

Example:

“Propose 5 different ways to create a metadata-capture workflow for a small lab, ranked by feasibility.”

Great for brainstorming and problem solving.

3.1.9 Evaluation Pattern

Use examples or rubrics to grade model output.

Example:

“Here are 3 example abstracts. Score the following abstract for clarity (1–5), structure (1–5), scientific accuracy (1–5). Provide justification.”

3.1.10 Game-play Pattern

Turn tasks into structured exercises. Define rules.

Example:

“We are going to play a game:
I describe a lab workflow, you generate 5 mistakes a junior researcher might make, and how to fix them.”

3.1.11 Recipe Pattern

Stepwise instructions with gaps.

Example:

“Fill in missing steps for this workflow:

  2. Load FASTQ files

  4. Align using BWA

  6. Generate BAM summary”

3.1.12 Template Pattern

Use placeholders → consistent output.

Example:

Mutation Summary

Gene: <GENE>

Variant: <VARIANT>

Impact: <IMPACT>

Evidence: <QUOTES FROM ARTICLE>

3.2 Text Manipulation Patterns

3.2.1 Semantic Filter

Remove or replace specific elements.

Example:

“Remove all dates from the text but change as little as possible.”

3.2.2 Meta-language Pattern

Define a micro-language the LLM should learn.

Example:

“When I write ‘QC-S1’, interpret it as: run initial QC on sequencing files and summarize FastQC results.”

3.3 Verifier Pattern

3.3.1 Cognitive Verifier Pattern

Meta-reasoning pattern where the model is instructed to generate an answer, independently verify, critique, or test that answer and revise if needed. Focuses on error detection, not explanation.

Typical prompt form:

“First provide an answer. Then verify it by checking assumptions, edge cases, and alternative interpretations.” “Critically review your own solution and correct any mistakes.”

What it does well - Reduces hallucinations - Improves factual and logical reliability - Surfaces hidden assumptions - Excellent for high-stakes outputs

What it is not - Not primarily about explaining reasoning to the user - Verification may be concise or structured rather than narrative

Example:

Answer: X

Verification: - Check assumptions → valid - Alternative method → same result - Edge cases → none violated

Conclusion: Answer stands.

3.3.2 Fact Checking Pattern

Force verification.

Steps:

  1. Extract facts
  2. Compare with source
  3. Flag inconsistencies
  4. Insert verified fact list at the end

Example:

“Extract all factual statements from the text and list any that need verification.”

3.4 Workflows

3.4.1 Working on smaller pieces

Outline Expansion Start small, expand in pieces.

Example:

“Here is the outline for a workshop. Expand only section 2. Keep the rest unchanged.”

3.4.2 Tail Generation

Add automatic “post-processing.”

Example:

“When done summarizing, also produce a 3-item action list.”
